**Multi-omic profiling identifies distinct baseline signatures predicting human neonatal antibody responses to hepatitis B vaccine**

This repository contains the code and analysis scripts used in the EPIC-HIPC multi-omic manuscript, investigating infant immune responses to hepatitis B vaccination using a systems biology approach that integrates omics data from neonatal peripheral blood (transcriptomics, epigenetics, flow cytometry) and plasma (proteomics, metabolomics) collected during the first week of life.
